- Super Admin: edit seller profile details and pictures; verify permissions and saved changes on phones.

## Done
- Staff Share Receipt: in Active Transit it opens WhatsApp on the buyer's chat with the receipt ready for staff to send; with no receipt yet it opens the scan page.
- Email confirmation: verified real confirmed-account return and reload on phone and desktop; signup-response tests retain first-time verification without repeat prompts for confirmed accounts.
- Unique payment codes: first reuse warns, second reuse blacklists the normalized phone; buyer and seller flows verified on phones and desktop, temporary test data removed.
- Dispatch form: multiple package types and optional description; verified saved details after reload at phone width.
- Receipts: green "Share Receipt" button sends the receipt to the buyer on WhatsApp; it then reads grey "Receipt Shared".
- Dispatch Receipts: filter by date and sending method (PSV, Pata Parcel, Pick-up Mtaani, Door to Door).
- Buyer complaints: WhatsApp, Call, and Resolve; verified resolved complaints leave the active list for sellers, staff, and admins.
- Confirm Delivered: the button disappears from the Active Transit card the moment it is tapped, and a red message appears if the save fails.
- Bottom bar (Dispatch / Receipts / Issues / Profile) now uses the header's green banner with a yellow top edge; unselected labels are solid white, the selected one is yellow. Checked at phone width with all 7 admin items — nothing clipped or blending in.
- Platform fee raised to KES 15/package.
- Dispatch form: pkg count and fee-per-pkg defaults are deletable placeholders.
- Pending-receipts red banner for staff/admin.
- Buyer phone uniqueness rule removed (one buyer may buy from many sellers).
- SACCO name prefilled from the seller's choice on the dispatch form.
- Staff Issues tab for platform-wide issue handling.
- Tracking codes: seller-name prefix + 6 digits; receipts shared by code (PSV only).
